# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub security advisories for this repository.

For package supply-chain issues, include:

- affected package version
- reproduction steps
- expected impact
- any relevant lockfile or install output

Do not open public issues for active vulnerabilities until they have been triaged.

## Scope

This repository contains the public TypeScript SDK and examples. Voyage Forge app internals, private backend services, and proprietary assets are out of scope for this repository.
